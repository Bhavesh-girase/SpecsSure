How it decides — evidence first, AI where it helps

Deterministic pipeline; every output line carries its source clause and the date it was checked

Input

text · voice · 7 languages · tender PDF (OCR) · GeM bid page

Understand

procurement glossary + loanword transliteration · item extraction from tenders

Retrieve

3-field BM25 (title · scope · product names) + bge-m3 multilingual embeddings, fused (RRF)

Decide

confidence from retriever agreement + coverage · abstain · withdrawn / title-only never “Recommended”

Expand

knowledge graph: normative refs, test methods, compliance tree (depth 1–4)

Resolve

edition in force · amendments · replacement · QCO · labs & charges

Output

result card · spec clause · Word · extension · REST / MCP API

The PS asks for multiple Indian languages. Most tender Hindi is transliterated English, so we romanise each word, reduce it to a sound skeleton and match it to the vocabulary of standard titles. Native words go through a procurement glossary, and the multilingual embeddings also read the original text. On a held-out set written before this work, the right standard is first 39% of the time and in the top 3 71% of the time with shortcuts off; 50% and 79% in product mode. It is our weakest area and the Evidence page says so.
